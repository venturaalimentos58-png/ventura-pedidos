Configuración (una sola vez)

Para guardar cambios acá necesitás un token de GitHub de este repositorio. Se guarda solo en este teléfono/navegador, nunca se comparte.

  1. Entrá a github.com → foto de perfil → Settings
  2. Developer settings → Fine-grained tokens → Generate new token
  3. En "Repository access" elegí solo ventura-pedidos
  4. En "Permissions" → Contents → Read and write
  5. Generá el token y pegalo acá abajo
